## Featured project

### [MEDIQ — Clinic Management & AI-Assisted Appointments](https://github.com/TPhu21/MEDIQ)

A full-stack project for patients, doctors, and clinic administrators, organized as one repository with a React frontend and nine Spring Boot services.

- Appointment booking, doctor availability, clinic management, and patient records.
- JWT authentication, role-based interfaces, and an API gateway.
- Integrations with Gemini AI, email OTP, and Cloudinary.
- Architecture diagram, local setup guide, and engineering notes included in the repository.
